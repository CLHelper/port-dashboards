Part 3 · Questions from non-developers

Q&A

Plain answers to what people ask most, and how not to get hacked while waiting.

Stay safe: the short version
  • The game is not playable yet on any PC project. Anything offered as a "playable build", "pre-patched exe" or "one-click installer" is fake and most likely malware.
  • Holy Interoperability is source code on GitHub, nothing else. A real project contains no game files and never asks you to download any.
  • Never turn off your antivirus, run a stranger's script, or type a password or a payment detail because a download page tells you to.
What is Holy Interoperability, in one sentence?

Compatibility layer: Runs the console executable's x86-64 code directly on the PC and supplies the console's system libraries and graphics API underneath it, translating the GPU programs on the way. Its repository is the source; this page only reads it.

How far is it right now?

Stage 4 of 8 on the shared ladder: First frame. A retail title creates its window, device and translated pipelines, streams start-up data and presents its first frame about 30 s in. It then stops in its own start-up code because its movie player uses pipelines that do not exist yet; nothing drawn has been seen.

Source: README status section. Read by hand on 2026-11-24; projects move fast, so check its commits for anything newer. How it compares with the others.

Where do I download the game files?

Not here, and not from any of these projects. They work only with a copy you already have, and this page won't point you to any source.

If someone sends you a link in a DM or a comment, treat it as a trap. Fake download sites are the oldest trick around a big release.

How do I check that my game_scarlett_master.exe is the right one?

The projects are built and tested against one executable. Compare your copy with it before you use it: if any value differs, it is another build or a changed file, so don't run it.

Several contributors checked the SHA-256 independently, and Leonida's docs and its tools/exe_sha.py use it. The SHA-1 is from the same file.

On Windows, in PowerShell: Get-FileHash game_scarlett_master.exe -Algorithm SHA1 (or -Algorithm SHA256).

A matching hash only tells you the file is the one others tested. It doesn't make the place you got it from safe.

How long until it's playable?

Nobody knows. Every project works the same loop: start the game, see where it stops, build the missing piece, start again. The jumps between stages are uneven: a project can go from the first frame to the menus in hours and then spend weeks on the world.

Playable on this ladder means 30 minutes in the game without a crash at 20 frames a second or better. Speed is usually the last and longest part.

What does the percentage at the top mean?

Where the project's stage sits on the shared ladder, from 0% (groundwork) to 100% (playable), with a little extra for how far it is into its stage compared with the others there. It counts milestones, not hours of work, so it can sit still for a long time.

Someone shared a "playable" download. Is it legit?

Check the standings. As long as no project is at "Playable", a playable download can't exist, so it is fake.

Even later, a virus scan alone isn't enough: someone who wants to hack people can build something that scans clean. Trust nothing you haven't built yourself from a project's own GitHub page, and don't blindly trust anyone who vouches for a file.

Can I help without writing code?

Often, yes: test runs on graphics cards the authors don't have, and clear bug reports with the exact build you ran. The work board above lists the open issues; read the project's README for how it wants reports.
